# Document Conversion Skill

## Overview
Transforms unstructured plain text files into formatted PDF documents (via ReportLab) and Word DOCX files (via python-docx).

## Operations
1. Ingests text stream with UTF-8 decoding.
2. Applies standard document styles (margins, line heights, font sizes).
3. Renders publication-ready PDF or Word document binary.
